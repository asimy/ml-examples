 cp# Income Classification Example from Chapter 4 of _Design an ML System (from Scratch)_

This example is based on the income classification example from Chapter 4 of _Design an ML System (from Scratch)_. The problem is to predict whether a person earns more than $50,000 per year based on the person's age, education, and occupation. The dataset is the [Adult Income dataset](https://archive.ics.uci.edu/ml/datasets/adult) from the UCI Machine Learning Repository. The example code in the notebook will walk through the experimentation phase of the ML Life Cycle laid out in Chapter 1 of the book:

1. Problem formulation
2. Exploratory data analysis (EDA)
3. Data collection/preparation
4. Data versioning
5. Model training
6. Model evaluation
7. Model validation
